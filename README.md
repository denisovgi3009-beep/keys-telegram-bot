# Telegram-бот продажи ключей подписки

Бот продаёт ключи (30/90/180 дней, 1 год): клиент выбирает срок → получает
реквизиты → жмёт «Я оплатил» → вам приходит уведомление → вы жмёте
«Подтвердить» → бот автоматически выдаёт свободный ключ со склада и шлёт его клиенту.

## Быстрый старт (Windows)

1. Создайте бота у [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте **токен**.
2. Узнайте свой **user id** — напишите [@userinfobot](https://t.me/userinfobot), он пришлёт число.
3. Откройте папку в терминале и выполните:

```bat
cd telegram-bot
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
notepad .env        :: впишите BOT_TOKEN и ADMIN_IDS
```

4. Закиньте ключи на склад (см. ниже) и запустите:

```bat
python bot.py
```

## Склад ключей

```bat
:: сгенерировать 20 тестовых ключей для товара 30d
python seed_keys.py --product 30d --gen 20

:: залить реальные ключи из файла (каждый с новой строки)
python seed_keys.py --product 90d --file keys.txt
```

id товаров: `30d`, `90d`, `180d`, `1y` (показать актуальные — команда `/stock`).

## Команды

| Кому | Команда | Что делает |
|------|---------|------------|
| клиент | `/start` | открыть витрину |
| админ | `/stock` | склад и id товаров |
| админ | `/addkeys 30d KEY1 KEY2` | добавить ключи |
| админ | `/orders` | заказы, ждущие оплаты |
| админ | `/help` | справка админа |

Подтверждение/отклонение оплаты — кнопками в уведомлении.

## Как устроено

- `config.py` — товары, цены, реквизиты оплаты, тексты.
- `db.py` — SQLite (`store.db`): товары, ключи, заказы. Выдача ключа атомарная —
  один ключ не уйдёт двум людям.
- `bot.py` — логика диалога на aiogram 3 (long polling).
- `seed_keys.py` — наполнение склада.

## Важно про оплату

Сейчас оплата — **ручная**: клиент переводит деньги сам (карта/крипта — реквизиты в
`config.py: PAYMENT_TEXT`), а вы подтверждаете вручную. Это самый простой и «безопасный»
вариант для продажи ключей.

Если хотите **автоматические платежи внутри Telegram** — подключите Telegram Stars
или Invoice API (`send_invoice`): тогда кнопка оплаты и выдача ключа будут происходить
без вашего участия. Скажите — допишу этот вариант.
